# Cardápio demonstrativo Açaí House

Protótipo estático inspirado no cardápio público fornecido para estudo de HTML, CSS e JavaScript. Não é o código original do OlaClick e não se conecta ao sistema de pedidos.

## Abrir no computador

Você pode abrir `index.html` diretamente no navegador. Para uma experiência mais confiável, rode um servidor local dentro desta pasta:

```bash
python3 -m http.server 8000
```

Depois abra `http://localhost:8000`.

## Publicar no GitHub Pages

1. Extraia o ZIP e coloque `index.html`, `README.md` e a pasta `assets/` juntos na raiz do repositório.
2. Envie todos os arquivos para o GitHub.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, a branch `main` e a pasta `/(root)`.
4. Salve e aguarde a publicação.

As imagens estão baixadas para `assets/`, então o site não depende de hotlink para exibi-las. Antes de publicar, peça autorização para reutilizar a marca e as fotos. Não se passe pelo estabelecimento nem sugira que a réplica aceita pedidos. Os botões de adicionar e a busca são apenas demonstrações locais.
